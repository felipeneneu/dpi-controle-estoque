# seams-cli Implementation Plan

> **For Antigravity:** REQUIRED WORKFLOW: Use `.agent/workflows/execute-plan.md` to execute this plan in single-flow mode.

**Goal:** Criar o utilitário headless de linha de comando `SeamsCLI` para automação completa do pipeline de emendas (cálculo geométrico, preflight CMYK e exportação para JPG ou PDF/X-1a) com `RESULT_JSON` estruturado.

**Architecture:** Aplicativo de console .NET 10 em `sidecars/SeamsCLI` estruturado em camadas: parser com `System.CommandLine` e validações estritas (R-013), executor desacoplado `SeamsWorkflowExecutor` que orquestra `imposition-core`, `imposition-render` e `imposition-pdf`, e emissor `JsonResultEmitter` que garante separação de `stdout` (JSON de resultado) e `stderr` (logs e progresso).

**Tech Stack:** .NET 10, C# 13, `System.CommandLine`, `Imposition.Core`, `Imposition.Render`, `Imposition.Pdf`, xUnit, FluentAssertions.

**Files:**

**Step 2: Gerar fixtures CMYK em runtime (sem commitar binários)**

**Step 3: Escrever testes de integração (Smoke E2E)**
Testar invocação do processo compilado (`dotnet run` ou executável direto):
1. **Cenário JPG:** Executar CLI passando JPG CMYK de teste e verificar exit code 0 e arquivos gerados no diretório de saída.
2. **Cenário PDF:** Executar CLI passando PDF CMYK de teste com `--format pdf` e verificar conformidade PDF/X-1a dos painéis gerados.
3. **Cenário Modo JSON:** Executar com `--json` e parsear `stdout` garantindo formato JSON estrito, campos `schemaVersion: "1.0"`, `warnings: []` e ausência de texto poluente.
4. **Cenário Erro de Parâmetro:** Executar com `--roll -50` e verificar exit code 1 e mensagem de erro em `stderr` (e JSON em `stdout` se `--json` presente).
5. **Cenário Mismatch:** Executar com arquivo `.jpg` e `--format pdf` e verificar exit code 1 com `E_FORMAT_MISMATCH`.
6. **Cenário Cancelamento SIGINT (bloqueante):** Disparar sinal de cancelamento durante a execução, verificar retorno de exit code 130 e ausência total de arquivos temporários residuais (`.tmp`).
