# Spec — regmark-cross.pdf

## Propósito
Marca de registro (cruz) para impressão offset multi-cor.

## Geometria

```
    │
    │
────┼────
    │
    │
```

| Parâmetro | Valor |
|---|---|
| Cruz horizontal | 8mm |
| Cruz vertical | 8mm |
| Espessura | 0.25pt |
| Cor | Registration (todas as cores) |
| Círculo | Raio 2mm (opcional) |

## Como criar no Illustrator
1. Desenhar cruz 8×8mm com stroke 0.25pt.
2. Cor: `Registration` (não preto).
3. Exportar como PDF.

## Validação
- [ ] Cruz 8mm × 8mm
- [ ] Cor Registration
- [ ] Stroke 0.25pt
